# Year 9 Textiles — shared module standard

## System ready

All eight module routes now use one shared `module-standard.css` layout source and the same semantic learning order:

1. lesson hero;
2. eight-slide presentation;
3. student evidence and progress;
4. theory explanation;
5. purposeful visual;
6. matched video or an honest teacher-source gap;
7. ten adjacent checks;
8. guided written evidence;
9. completion and onward navigation.

The shared geometry follows the Desk Tidy contract: 1180 px desktop maximum, 295 px minimum lesson hero, 72 px content inset, 24 px card rhythm, 21.6 px card padding, 680 px collapse and 40 px / 46 px mobile heading. The plum hero is the only course-specific colour surface; learning cards and fields use the neutral shared system.
